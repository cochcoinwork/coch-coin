# COCH COIN — demo

Це стартовий статичний прототип Telegram Mini App.

## Як опублікувати
1. Завантажте `index.html` у GitHub-репозиторій `coch-coin`.
2. Імпортуйте репозиторій у Vercel та натисніть Deploy.
3. Скопіюйте HTTPS-адресу Vercel і додайте її в BotFather через `/setmenubutton`.

## Важливо
Це лише демонстрація: бали зберігаються в localStorage конкретного браузера. Немає сервера, бази даних, захисту від підробки балансу чи справжнього токена CHC. Не обіцяйте гравцям обмін балів на гроші або токени. Для реального запуску потрібні backend, база даних і серверна перевірка Telegram WebApp initData.
